EdgeTX Pilot Info Splash Screen Generator

Version 1.1.2 — Complete User Guide
by Mark Ptaszynski  |  March 2026
The EdgeTX Pilot Info Splash Screen Generator is a Windows desktop application that creates a personalised pilot identification card image (480 × 272 pixels) for use as the startup splash screen on EdgeTX colour-screen radio transmitters such as the RadioMaster TX16S MK I/II. It displays your name, address, phone number, and regulatory identification numbers (AMA, FAA, and TRUST) every time the radio powers on — providing an at-a-glance ID card for field use. The program gives you full control over layout, colours, fonts, and a custom background image, then saves the finished graphic directly to the radio SD card or to your PC.

2.  Group 1 — Pilot Info File

This panel at the top of the left column is where you get pilot data into the program. There are three ways to load data from files and one way to enter it directly without a radio.

2.1  Auto-Detect Button

Scans every logical drive connected to your PC looking for the file SCRIPTS\TOOLS\PilotInfo.txt — the file created on the SD card by the PilotInfo Lua script on the radio. When found, it reads all seven data fields, populates the Pilot Data panel, and immediately generates a preview.

ⓘ Before clicking Auto-Detect: Connect the radio via USB cable and on the radio screen select System Settings → USB Mode → USB Storage (SD). Wait for the drive to appear in Windows Explorer before clicking the button.

2.2  Drive Text Box

Displays the drive root path found or selected, for example E:\. Set automatically by Auto-Detect or Browse.

2.3  Browse… Button

Opens a Folder Browser dialog so you can manually navigate to the SD card root folder. Use this if Auto-Detect cannot find the drive — for example if the SD card is in a standalone card reader rather than in the radio.

2.4  Open PilotInfo.Txt Button

Opens a file browser dialog so you can select any PilotInfo.txt file anywhere on your PC — no radio required. After selecting, data loads and the preview regenerates automatically. This is the fastest way to work when you have a previously saved PilotInfo.txt.

2.5  Enter Pilot Info Button

Opens the Enter Pilot Information dialog (see Section 7) where you type all seven fields directly. Use this when you have no radio or saved PilotInfo.txt available. After clicking OK the data loads and the preview regenerates.

4.  Group 3 — Appearance

This is the main design studio for your splash card. It is divided into four sub-sections separated by horizontal lines. Almost every control updates the preview instantly.

4.1  Background Sub-section

Background Template text box

Shows the filename of the selected background image. When empty the built-in gradient design is used. Typing directly into this box also triggers a preview refresh.

Browse… Button (background template)

Opens a file dialog filtered to PNG, JPG, JPEG, and BMP. The chosen image is scaled to fill the 480 × 272 canvas. A semi-transparent dark tint is then overlaid so all text remains readable regardless of the image content.

Clear Button (background template)

Removes the selected image and returns to the built-in gradient background immediately.

Background Color Button

Opens the Windows color picker for the background color used in the built-in gradient (default: dark navy #12203A). Has no visible effect when a template image is loaded.

Dark Tint Slider

Controls the opacity of a black overlay drawn over the background image. Slide left for a lighter, more image-visible result; slide right for darker, better text contrast. Range: 0% (no tint) to 100% (solid black). Default: approximately 63%.

ⓘ The Dark Tint slider only has an effect when a background template image is loaded. It does not affect the built-in gradient.

4.2  Both Bands Color (Accent Color Button)

Opens the color picker and applies the chosen color to both the top accent band and the bottom ID band simultaneously. The quickest way to keep both bands matching. Individual band colors can then be fine-tuned separately using their own Set Color buttons.

4.3  Top Accent Band Sub-section

The top band runs across the full card width at the very top and contains the title text “PILOT IDENTIFICATION CARD”.

ControlWhat it Does

Set Color (top band)Opens the color picker for the top band independently of the bottom band.
Opacity slider (top band)Controls the transparency of the top band fill. 0% = fully transparent, 100% = fully opaque. Default: 100%. The percentage label updates in real time as you drag.
Top Accent Band Text (button)Opens the Font dialog for the title text. Change font family, size, style, and color. Default: Segoe UI 14pt Bold, White.
Top Accent Label (button)Opens the Font dialog for the small field labels (e.g. “Street Address:”) shown in the contact area when Show contact labels is ticked. Default: Segoe UI 8pt Regular, White.

4.5  Bottom ID Band Sub-section

The bottom band spans the full card width across the lower portion and contains the three regulatory ID numbers: AMA #, FAA #, and TRUST #.

5.  Right Column — Preview and Instructions

5.1  Preview Panel

Displays the splash card at its actual pixel dimensions: 480 × 272. This is exactly the size that will be written to the radio SD card. What you see is what you get.

  • The preview regenerates automatically when you change almost any control.
  • Placeholder dashes (—) appear for any field that has not been filled in yet.
  • Background images are auto-scaled to fill the full 480 × 272 area.

5.2  Step-by-Step Instructions Panel

A large text panel below the preview contains a built-in quick-start guide. It describes the recommended workflow for connecting the radio, loading pilot data, customising the appearance, and saving the splash image. For reference only — you do not need to follow the steps in order.

6.1  Status Bar

A text strip at the bottom of the window shows status messages as you work. Normal messages appear in dark text; errors appear in red. Examples:

  • Preview ready — click Save Splash Screen to write splash.png.
  • Pilot data saved to: C:\Users\…\PilotInfo.txt
  • Error messages in red when a drive is not found or a file cannot be read.

10.  Typical Workflows

10.1  First-Time Setup with Radio Connected

  1. Connect the radio to your PC via USB cable.
  2. On the radio screen select System Settings → USB Mode → USB Storage (SD).
  3. Wait for the SD card drive to appear in Windows Explorer.
  4. Launch the EdgeTX Pilot Info Splash Screen Generator.
  5. Click Auto-Detect. If the SD card is found, pilot data loads and the preview generates.
  6. If Auto-Detect fails, click Browse… and navigate to the SD card root drive.
  7. Review the Pilot Data panel. If values are wrong, click Enter Pilot Info to correct them.
  8. Customise the appearance using the Group 3 controls (Section 4).
  9. When satisfied with the preview, click Save Splash Screen and save.
  10. Copy splash.png to IMAGES\ on the SD card if you did not save directly to the card.
  11. Safely eject the SD card drive in Windows, then disconnect the USB cable.
  12. Power cycle the radio to see your new splash screen.

10.2  Designing Without a Radio

  1. Launch the program.
  2. Click Enter Pilot Info, fill in all seven fields, then click OK.
  3. Customise the appearance using the Group 3 controls.
  4. Click Save Splash Screen to save the image to your PC.
  5. Click Save Pilot Info to save a PilotInfo.txt file to your PC.
  6. When you connect the radio later, copy splash.png to IMAGES\ and PilotInfo.txt to SCRIPTS\TOOLS\ on the SD card.

10.3  Updating an Existing Splash Screen

  1. Load your previous PilotInfo.txt using Open PilotInfo.Txt or Auto-Detect.
  2. Adjust any appearance settings that need updating.
  3. Click Save Splash Screen to overwrite the previous file.

11.  Splash Card Layout Reference

The 480 × 272 canvas is divided into four horizontal zones:

Zone (Y pixels)Content
0 – 44 pxTop Accent Band — “PILOT IDENTIFICATION CARD” title, centred horizontally.
44 – 104 pxName Area — Pilot name in large bold font, centred horizontally.
104 – 196 pxContact Area — Street Address, City/State/ZIP, and Phone. Labels optional.
196 – 272 pxBottom ID Band — AMA #, FAA #, and TRUST # in stacked or 3-column layout.
ⓘ The 480 × 272 resolution matches the TX16S MK I and MK II screens. The TX16S MK III / MAX uses 800 × 480 and is not directly supported without source code changes.

12.  Tips and Troubleshooting

12.1  SD Card Not Found by Auto-Detect

  • Confirm you selected USB Storage (SD) on the radio, not USB MIDI or another mode.
  • Give Windows 10–15 seconds to register the drive, then try again.
  • Open Windows Explorer and confirm the drive letter appears. If so, use Browse… to select it manually.
  • Try a different USB cable or port if the drive never appears in Explorer.

12.2  PilotInfo.txt Not Found on the SD Card

  • The file is only created after the PilotInfo.lua script has been run at least once on the radio via the Tools menu.
  • If the Lua script has not been run yet, use Enter Pilot Info or Open PilotInfo.Txt instead.

12.3  Text is Clipped or Overflows in the Preview

  • Try a slightly smaller font size via the Pilot Name Font or Address / Phone Text buttons.
  • Keep values within the character limits shown in the Enter Pilot Info dialog.

12.4  Background Image Looks Very Dark

  • Reduce the Dark Tint slider — drag it left to lower the percentage.
  • The tint is intentional to ensure white text is readable over any photograph.

12.5  Preview Does Not Refresh After a Change

  • Click Re-Generate Preview to force a manual refresh.
  • Check the Status bar for an error message shown in red.

12.6  Save Splash Screen Button is Disabled

  • The button enables only after a successful preview render. Click Re-Generate Preview first.

12.7  Colors Look Different on the Radio vs. the Preview

  • The radio LCD may render colors differently to a PC monitor due to its display technology.
  • Choose colors with strong contrast for best readability in bright sunlight at the flying field.

Appendix — Compatible Radio Models

The program generates a 480 × 272 pixel PNG by default, matching these radios:

  • RadioMaster TX16S MK I
  • RadioMaster TX16S MK II
  • RadioMaster TX16S MK II MAX
  • RadioMaster Boxer
  • RadioMaster Pocket
  • Jumper T16
  • Jumper T18

Radios with different screen resolutions (such as the TX16S MK III / MAX at 800 × 480) are not directly supported without modifying the SPLASH_W and SPLASH_H constants in the program source code.
